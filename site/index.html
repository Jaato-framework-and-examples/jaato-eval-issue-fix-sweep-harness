By model

Ranges, not means. Every figure reads [min … max] with the number of observations behind it. A mean would claim a central tendency across runs that may have executed under different framework versions; a range claims only observed extent.

The population differs by figure. Cost, duration, turns and cache hit range over arms. Pass rate ranges over runs — an arm's pass rate is 0 or 1, which is not a rate.

A figure showing n=3 of 5 was built from three observations where five existed — an unreported cost is dropped, not counted as zero, and a run in which every arm was BLOCKED contributes no pass rate at all. A figure showing no such label was built from everything that existed. BLOCKED never enters a denominator, and is always shown.

Cache hit is the share of billed tokens served from cache. It reads “not observed” for runs produced before the runner recorded that figure; the last-response reading those older rows carry is not a spend and is not substituted for it.

Agreement is the share of arms that produced the single most repeated payload. 0% means no two arms matched — not “half matched”. An arm that answered nothing stays in the denominator: it did not disagree, but it did not reproduce the answer either, so the count of arms that answered is shown whenever it is short. Below two answers there is no figure at all — one observation can neither agree nor disagree.

By model is not a league table. It groups the same arms by the model that ran them. Comparing a column — two models on one issue — is fair: identical criteria, identical fixture. Comparing a row is not, because the issues are not equally rigorous and the models have not attempted the same ones. That is why a model shows its record per issue and no overall pass rate: a model with one pass and a model with three would otherwise both read 100%.
